## What is TrenchersAI?

We're launching with a **trading terminal** similar to GMGN , Trojan, Axiom,  built for speed, simplicity, and the trenches. Same power, lower fees, and more rewards for traders. Snipe launches, copy wallets, track whale moves, and manage positions all in one place on Solana.

From there, we expand into spawnable AI trading bots across prediction markets (Polymarket, Kalshi), cross,platform arbitrage, DeFi yield, and sports/event markets. The terminal is day one — the app store for AI trading agents is where we're headed.

**The market right now:** 80%+ of crypto volume is bot driven. 14 of the top 20 most profitable Polymarket wallets are bots. One bot turned $313 into $414K in a single month. Trenchers are already using AI to snipe launches, copy whale wallets, and farm prediction markets — but there's no single platform that lets everyday users access all of this without coding.

**Design and code the TrenchersAI landing page in Next.js.

This page must do three things in ~5 seconds:

1. **What is this?**

- Performance: fast load, strong Lighthouse

**Deliver**

- GitHub repo + Vercel deploy

## Assignment 3 — Pressure Test: Real-Time Data UI

**Build a single component that displays live or simulated real-time trading data — and make it feel alive without jank.**

**Requirements**

- 10–15+ rows updating in real time (WebSocket / polling / simulated)
- Visual feedback for changes (tasteful)
- Handles rapid updates gracefully (no flicker, no layout shift)
- At least one interaction (sort/filter/expand/favorite)

**We’re judging**

- Performance under load (re-render efficiency)
- Animation taste and restraint
- Data hierarchy under motion
- Code architecture and polish (hover/loading/empty/error)

**Deliver**

- GitHub repo + Vercel deploy
